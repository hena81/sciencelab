# نظام خزانات المختبرات

تطبيق ويب لإدارة خزانات مختبر الأحياء والجيولوجيا، يدعم العربية وواجهة متجاوبة ولوحة تحكم للأدمن.

## التشغيل

### على SmarterASP.NET

ارفع هذه الملفات والمجلدات إلى `wwwroot` أو جذر الموقع في الاستضافة:

```text
index.html
about.html
app.js
data.json
api/data.php
App_Data/data.json
App_Data/web.config
```

بعد الرفع افتح هذا الرابط في المتصفح:

```text
https://your-domain.com/api/data.php
```

إذا ظهرت بيانات JSON، فالتخزين المشترك يعمل. بعد ذلك افتح الموقع من الديسكتوب والهاتف بنفس رابط الدومين.

إذا ظهرت رسالة خطأ عند الحفظ، تأكد من أن مجلد `App_Data` قابل للكتابة من لوحة تحكم SmarterASP.NET أو من مدير الملفات.

### تشغيل محلي

شغله عبر الخادم المرفق حتى تشترك كل الأجهزة في نفس ملف `data.json`:

```powershell
node server.js
```

ثم افتح من جهاز الديسكتوب:

```text
http://localhost:8080
```

ولفتح الموقع من الهاتف، اجعل الهاتف والديسكتوب على نفس شبكة Wi-Fi، ثم اعرف IP جهاز الديسكتوب:

```powershell
ipconfig
```

استخدم قيمة IPv4، وافتح من الهاتف مثلاً:

```text
http://192.168.1.25:8080
```

## تسجيل الدخول

- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

## التخزين

- يبدأ التطبيق من ملف `data.json`.
- على SmarterASP.NET يتم الحفظ في `App_Data/data.json` عبر `api/data.php`.
- عند التشغيل بـ `node server.js` يتم حفظ أي إضافة أو تعديل في `data.json` على جهاز الديسكتوب.
- أي هاتف يفتح نفس رابط الشبكة يقرأ البيانات نفسها من الخادم.
- إذا فتحت الملف مباشرة أو شغلته بخادم عادي مثل `python -m http.server` فسيعود الحفظ ليكون محلياً داخل متصفح ذلك الجهاز فقط.
